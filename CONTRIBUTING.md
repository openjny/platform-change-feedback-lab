# Contributing

Start from an issue for the change. Review the [planner checks](README.md#run-the-planner)
and record what ran in the pull request. Keep follow-up proposals separate
from the application change they came from.

Use only made-up resource names, requirements, and project data. Never copy
local chat logs, real cloud configuration, or credentials into the repository.
For inputs this repository must not disclose, see [SECURITY.md](SECURITY.md).

The maintainer decides whether a proposal is worth adopting. This lab's
post-merge issue writer is limited to the repository owner's same-repository
merges into `main`; contributions from forks do not get write permissions.
