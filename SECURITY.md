# Security

Use GitHub's [private reporting guidance](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
for nonpublic security details. Do not post credentials or sensitive reports
as public issues or PR comments.

The sample is not a security scanner. Its automation reads public synthetic
PR data and files process improvement proposals. It never gives the model
shell access or a GitHub token. The maintainer reviews proposals before making
any changes based on them.
